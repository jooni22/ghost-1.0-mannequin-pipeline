## 🚀 What You Need to Do (2 Minutes)

### Step 1: Create `.env.local` file

```bash
# Copy the template
cp .env.example .env.local

# Edit with your API keys
nano .env.local
```

Add these two required keys:
```env
FAL_API_KEY=your_key_from_fal.ai
GEMINI_API_KEY=your_key_from_google
```

**Get keys from:**
- FAL: https://fal.ai/dashboard
- Gemini: https://aistudio.google.com/app/apikey

### Step 2: Test it works

```bash
npm test
```

## 🎨 What This Project Does

**Ghost Mannequin Pipeline** transforms flat garment images into professional product photos with:

- 👻 **Ghost mannequin effect** - Invisible form showing interior
- 🏷️ **Label preservation** - Keeps brand logos intact
- 🎨 **Color accuracy** - Precise hex color matching
- 🧵 **Construction fidelity** - Preserves seams and stitching
- 💰 **Cost optimization** - 97% token reduction via Files API
- 🎯 **Multiple modes** - Ghost, flatlay, on-model, virtual try-on
